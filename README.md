# Skills-Link

## Project Overview

Skills-Link is a web-based job recruitment platform designed to connect job seekers with employers. The system allows employers to post job opportunities, while job seekers can search for available jobs and submit applications online.

The aim of the project is to make the recruitment process easier, faster and more accessible.

## Features

- **User Registration:** Users can create accounts on the platform.
- **User Login:** Registered users can securely access their accounts.
- **Job Posting:** Employers can publish available job opportunities.
- **Job Searching:** Job seekers can browse available job listings.
- **Job Applications:** Applicants can apply for jobs.
- **Application Management:** Users can manage and view job applications.
- **User Roles:** Different users have access to different system features.

## Technologies Used

- **Angular** – Front-end application development.
- **HTML** – Structure of web pages.
- **PHP** – Server-side development and application logic.
- **SQL** – Database management and storage.

## Installation and Setup

1. Clone or download the repository from GitHub.
2. Install the required development tools.
3. Set up the Angular environment.
4. Open the project in your preferred code editor.
5. Configure the PHP backend.
6. Set up the SQL database.
7. Import the database if an SQL file is provided.
8. Configure the database connection in the PHP files.
9. Run the PHP backend and Angular application.
10. Open the application in your browser.

## Database

The SQL database stores information such as:

- User details
- Employer information
- Job listings
- Job applications
- User roles

## Project Purpose

Skills-Link was developed as an academic project to demonstrate the use of web development technologies in creating a job recruitment platform. It provides a platform where employers and job seekers can connect through job advertisements and applications.
